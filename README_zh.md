# 合同审查数据集

面向指定立场方的合同风险识别评测集，可用于论文复现和方法比较。数据基于真实合同，经脱敏或改写构建。本仓库提供的是完整数据集的采样示例。

- 40 份 Markdown 合同，覆盖 8 类业务，每类 5 份；含中文、英文及中英双语文本。
- 20 个审查点，包含适用范围、触发条件和豁免条件。
- 每份合同指定立场方，共 800 个合同—审查点二元标签：130 个“有风险”、670 个“无风险”。
- 32 份合同含正标签，8 份合同全为负标签。

## 数据说明

“有风险”表示合同在指定立场下命中对应审查点。当前只有合同级二元标签，没有证据片段、逐项理由或严重程度标注。

## 目录与数据格式

```text
.
├── README.md
├── README_zh.md
├── contract_general_review_points.json   # 20 个审查规则
├── risk_labels.csv                       # 合同元数据与标签
├── contract_texts/                       # 八个业务类别目录，每类 5 份合同
└── scripts/validate_dataset.py           # 本地校验脚本
```

数据文件使用 UTF-8；CSV 可用 `utf-8-sig` 兼容 BOM，字段含逗号，请使用标准 CSV 解析器。部分文本为订单或确认书，可能引用未提供的主协议，附件也可能省略。不要自动修正文本差异，它们可能对应风险标签。

### 审查规则 JSON

每个对象包含：

| 字段 | 含义 |
| --- | --- |
| 审查点标题 | 完整规则标识，不得重复 |
| 审查点描述 | 适用范围、判定步骤、触发条件及豁免条件 |
| 备注 | 可选的配置说明 |

`保密条款*`、`争议解决*` 的星号属于标题本身。`禁止对外发布条款` 的“指定主体字样”需使用方配置，本数据集未提供具体关键字。部分规则涉及集团关系等背景，不应虚构未提供的信息。

### 标签 CSV

每行对应一份合同，共 28 列：8 个元数据或汇总字段、20 个规则标签字段。标签列名为 `规则_<审查点标题>`，值为 `有风险` 或 `无风险`。

| 字段 | 含义 |
| --- | --- |
| 序号 | 唯一样本 ID，当前为 1—40 |
| 标的大类 | 业务类别，与路径中的类别目录一致 |
| 合同名 | 展示名称，不要求与文件名或正文标题完全一致 |
| 文件名 | 合同相对路径，格式为 `contract_texts/类别/合同名.md` |
| 立场方、立场方角色 | 审查所服务的主体及其角色，属于模型输入 |
| 风险条数 | “有风险”标签数量，范围 0—7 |
| 命中审查点 | 正标签标题，以中文分号 `；` 分隔；无正标签时为空 |

## 读取数据

以下示例在仓库根目录运行，仅需 Python 标准库：

```python
import csv
import json
from pathlib import Path

root = Path.cwd()
review_points = json.loads(
    (root / "contract_general_review_points.json").read_text(encoding="utf-8")
)
with (root / "risk_labels.csv").open(encoding="utf-8-sig", newline="") as source:
    record = next(csv.DictReader(source))

sample = {
    "contract_text": (root / record["文件名"]).read_text(encoding="utf-8"),
    "review_party": record["立场方"],
    "review_party_role": record["立场方角色"],
    "review_points": review_points,
}
reference_labels = {
    point["审查点标题"]: int(record[f"规则_{point['审查点标题']}"] == "有风险")
    for point in review_points
}
```

模型输入包括合同正文、立场及规则。不要把“风险条数”“命中审查点”或任何参考标签作为输入；输出缺失或不可解析时应记录失败，不要静默补零。

## 本地校验

要求 Python 3.10+ 和 `uv`，无第三方 Python 依赖。在仓库根目录运行：

```bash
uv run scripts/validate_dataset.py
```

脚本只读检查字段、路径、文件关联、规则与标签对应关系，以及“风险条数”“命中审查点”的一致性。成功返回 `0` 并输出统计和 SHA-256 数据指纹，失败返回 `1`；不修改文件、不调用外部 API。脚本不验证标签的法律正确性、脱敏充分性或公开授权。
