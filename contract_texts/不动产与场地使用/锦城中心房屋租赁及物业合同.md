# 第二部分　通用租赁合同条款

# 一、租赁房屋情况

1. 乙方承租甲方项目房屋具体信息详见第一部分主要租赁条件。乙方已现场查看过该房屋，对其位置及条件表示满意并接受。

# 二、用途及房屋名称

1. 该房屋用途为办公用房，乙方不得擅自变更。
2. 乙方应以第一部分主要租赁条件第三条所列名称作为该房屋的标示名称。

# 三、租赁期

1. 租赁期列于第一部分主要租赁条件第四条。租赁期届满不免除双方在租赁期届满前尚未履行的义务。

# 四、该房屋的交付

1. 甲方应于交付日将该房屋连同现有装修及设施（详见附件二）交付乙方使用。
2. 交付时双方应共同验收并签署交接单，作为本合同附件三。

甲方负责该房屋主体结构、公共区域及公共设施的维修养护，保障房屋处于正常可使用状态。甲方进行维修应提前通知乙方，紧急情形除外。

# 六、乙方的维修保养责任

乙方负责该房屋内部非公共设施的日常维护，因乙方使用不当造成损坏的，由乙方负责修复或承担修复费用。

# 七、安全管理责任

乙方应遵守甲方及该项目物业管理方制定的安全管理制度，落实消防、治安等安全责任。乙方应签署附件四《安全管理责任承诺书》。

# 八、该房屋的交还

租赁期届满或本合同提前终止、解除的，乙方应于交还日将该房屋及其附属设施恢复至交付时状态（正常损耗除外）并交还甲方，同时结清全部应付费用。

# 九、租金、物业管理费及支付

1. 租金、物业管理费标准及支付方式详见第一部分主要租赁条件第五条。
2. 乙方应按本合同约定的周期、方式和时间节点缴纳各项费用。

# 十、保证金

保证金的缴纳、扣除与退还详见第一部分主要租赁条件第六条。甲方依约从保证金中扣款后，乙方应于收到书面通知后七日内补足保证金。

# 十一、转让、转租

1. 未经甲方事先书面同意，乙方不得将该房屋全部或部分转租、分租，不得将本合同项下权利义务转让给第三方。
2. 甲方转让该项目所有权的，应保证受让方继续履行本合同，本合同对受让方具有约束力。乙方在同等条件下享有优先承租权。

# 十二、甲方的权利及义务

1. 甲方有权按约定收取租金及相关费用。
2. 甲方应保障乙方在租赁期内对该房屋的正常使用，非因法定或约定事由不得干扰乙方使用。
3. 甲方应履行本合同约定的维修养护义务。

# 十三、乙方的权利及义务

1. 乙方有权在租赁期内按约定用途正常使用该房屋。
2. 乙方应按时缴纳租金、物业管理费、公用事业费及保证金。
3. 乙方应合法使用房屋，不得从事违法违规活动，不得存放危险物品。

# 十四、免责

因不可抗力、政府行为或市政建设等非甲方过错原因导致该房屋无法正常使用或本合同无法履行的，双方互不承担违约责任，相关费用据实结算。

# 十五、保险

乙方应就其在该房屋内的财产及经营活动自行投保相应保险。甲方已就该项目公共区域投保相应保险。

# 十六、乙方违约

1. 乙方逾期支付租金、物业管理费等应付款项的，每逾期一日，应按逾期应付金额的万分之五向甲方支付违约金。
2. 乙方逾期超过三十日仍未支付的，甲方有权书面通知乙方解除本合同，收回该房屋，并从保证金中抵扣欠费及违约金。
3. 乙方擅自改变房屋用途、擅自转租或从事违法活动的，甲方有权解除本合同并要求乙方赔偿损失。

# 十七、甲方违约

1. 甲方未按约定交付房屋或未履行维修义务致使乙方无法正常使用的，应按实际影响期间减免相应租金，并赔偿乙方因此遭受的直接损失。
2. 甲方非因法定或约定事由提前收回房屋的，应退还剩余期间已付租金及保证金，并按一个月租金标准向乙方支付违约金。

# 十八、终止合同

1. 经双方协商一致，可以解除本合同。
2. 出现本合同约定的解除情形的，守约方有权书面通知违约方解除本合同。
3. 本合同解除或终止的，双方应据实结算费用，乙方应按约定交还房屋。

# 十九、通知

与本合同有关的通知、文件均须采用书面形式，以专人送达、快递或电子邮件方式发送至附表一载明的联系地址。以专人送达的，签收时视为送达；以快递方式发送的，交寄后第三日视为送达；以电子邮件方式发送的，发送成功之时视为送达。一方联系信息变更的，应提前书面通知另一方。

# 二十、税费

双方因签订和履行本合同应缴纳的税费，依照法律法规各自承担。

# 二十一、适用法律及争议的解决

1. 本合同之效力、解释、变更、执行及争议解决均适用中华人民共和国法律。
2. 因本合同产生或与本合同有关的任何争议，双方应友好协商解决；协商不成的，任何一方均有权向甲方所在地有管辖权的人民法院提起诉讼。

# 二十二、保密

双方对因签订、履行本合同而知悉的对方商业秘密及未公开信息负有保密义务，未经对方书面同意不得向第三方披露，法律法规另有规定或监管部门要求的除外。本条义务不因本合同的解除或终止而失效。

# 二十三、不可抗力

1. 因地震、台风、洪水、火灾、战争、疫情、政府行为等不可抗力致使一方不能履行或不能完全履行本合同的，遭遇不可抗力的一方应及时书面通知另一方，并在合理期限内提供有权机构出具的证明。
2. 因不可抗力造成的损失，双方互不承担责任。不可抗力影响持续超过九十日的，任何一方均有权书面通知对方解除本合同。

# 二十四、其它

1. 本合同未尽事宜，双方可另行签订书面补充协议，补充协议与本合同具有同等法律效力。
2. 本合同的条款相互独立，部分条款无效不影响其余条款的效力。
3. 本合同自甲乙双方签字并加盖公章或合同专用章之日起生效，一式肆份，甲乙双方各执贰份，具有同等法律效力。

# 二十五、反商业贿赂条款

1. 双方承诺在订立和履行本合同过程中严格遵守国家反商业贿赂法律法规，不得以任何形式向对方工作人员或相关第三方给予、收受回扣、礼金、有价证券、贵重物品或其他不正当利益。
2. 任何一方违反上述约定的，守约方有权解除本合同，并要求违约方赔偿由此造成的全部损失。
