甲、乙双方经过平等友好协商，就甲方委托乙方代理销售其冰雪主题景区及极地馆景区营销事宜，一致达成以下条款，以资共同遵守。甲方一为乙方提供旅游大数据、一键智慧游、语音播报、智能导览服务，甲方二为乙方提供旅游推广服务事宜，甲方一、甲方二合称甲方，甲方、乙方合称双方。双方同意本协议为年度营销代理框架协议，用于约定双方在合作期限内的代理权限营销合作、结算方式及通用权利义务。

# 1. 定义

1.1 旅游大数据：是指甲方及关联方利用自身技术与数据优势，通过API形式为旅游服务从业机构所提供的，使得旅游服务从业机构能够高效了解其旅游经营场所运营情况的产品。

1.2 一键智慧游：是指甲方及其关联方利用自身技术与数据优势，为旅游服务从业机构所提供的，使得其游客可通过移动客户端享受到的智慧游览的服务。

1.3 语音播报：是指甲方及关联方利用自身技术与数据优势，为旅游服务从业机构所提供的，使用户在开启驾车导航场景下，途径景区一定公里范围内的道路行驶过程中，有机会收听播报内容的服务。

# 2. 合作内容

2.1 乙方作为甲方文旅产品的营销代理方，负责在其渠道推广甲方指定的景区门票、套餐及组合产品。

2.2 乙方应严格按照甲方确认的价格体系对外销售，不得低于约定价格销售，不得拆分售卖组合产品。

2.3 乙方客户提供的播报内容不得违反广告法、反不正当竞争法等法规，甲方有权对播报内容进行审核并决定是否允许上线。

# 3. 合作期限与价格

3.1 合同有效期：双方约定合作期限为三年，附件产品价格有效期为一年，一年后价格政策双方签署补充协议或通过联系人邮箱另行约定。

3.2 播报数据存储期限为30天，乙方如需获取应当及时向甲方调取。

# 4. 结算方式

4.1 双方按自然月结算。乙方应于每月结束后十个工作日内向甲方提供上月销售明细，甲方确认后十五个工作日内结算。

4.2 结算款项以人民币计价。乙方收款账户信息：

   开户银行：中国工商银行股份有限公司哈尔滨松北支行
   银行账号：35020166889052500789

4.3 乙方开具增值税专用发票，适用税率为6%。

# 5. 授权素材

5.1 乙方应当在双方确定的期限内为甲方提供景区、酒店等涉旅地点的基础资料，包含图片、文字、音视频、文件等内容（以下简称"授权素材"），以用于文旅产品的展示及宣传。

5.2 甲方及其关联方对前述授权素材享有合法的使用权，并可根据自身业务调整对景区的授权素材进行非实质性修改及合理使用。

# 6. 品牌使用

6.1 本协议有效期内，本协议一方获得另一方书面授权后方可基于履行本协议的目的使用另一方的商标、标识等产品或服务标志以及企业名称、标识。

6.2 如乙方需使用天穹的商标、标识及其他品牌元素，应当按照天穹品牌使用授权规定签署书面品牌授权使用协议，视觉设计及物料上线使用前需经过天穹书面或邮件同意后方可使用。双方应当保证该等使用仅限用于本协议下的合作事项、品牌范围和被授权人名称，未经允许不可转授权。如本协议终止，上述授权自动终止。

# 7. 保密条款

7.1 本协议项下的"保密信息"是指：在为达到本协议合作目的进行评估、磋商、谈判、合作的过程中，一方（简称"披露方"）向另一方（简称"接收方"）提供的任何有关披露方的业务、财务、技术等方面的非公开的商业信息。

7.2 接收方应对保密信息予以保密，未经披露方书面同意不得向第三方披露，仅为履行本协议之目的使用。

7.3 本条规定的保密义务不受本协议期限的限制，在本协议终止后仍然有效。

# 8. 违约责任

8.1 任何一方违反本协议约定给对方造成损失的，应当依法承担相应的赔偿责任。

8.2 一方迟延履行结算义务的，每逾期一日应按应付未付金额的万分之五向对方支付违约金。

# 9. 协议期限与终止

9.1 本协议自双方加盖公章或合同专用章后于【2026】年【3】月【127】日起生效，有效期至【2027】年【3】月【31】日。

9.2 本协议期满前三十日，双方可协商续签事宜。

9.3 本协议可通过如下方式提前终止：9.3.1 双方书面协商一致提前终止本协议的，本协议自协商终止之日起解除；9.3.2 一方进入破产申请或清算程序的，另一方有权终止本协议。

# 10. 不可抗力

因地震、台风、洪水、火灾、战争、疫情、政府行为等不可抗力致使一方不能履行本协议的，遭遇方应及时书面通知另一方并在合理期限内提供证明，双方互不承担责任。

双方承诺在订立和履行本协议过程中严格遵守国家反商业贿赂法律法规，不得以任何形式向对方工作人员或相关第三方给予、收受不正当利益。一方违反本条约定的，守约方有权解除本协议并要求赔偿损失。

# 12. 法律适用及争议解决

12.1 本协议之效力、解释、变更、执行及争议解决均适用中华人民共和国法律。

12.2 因本协议产生或与本协议有关的任何争议，双方应友好协商解决；协商不成的，任何一方均有权向甲方一所在地有管辖权的人民法院提起诉讼。
